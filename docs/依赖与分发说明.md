# 知拾依赖许可记录

本构建用于本机测试与个人使用，尚未签名，不作为已完成公开分发合规审查的发行版。

- Electron、React、Vite、PDF.js、FastAPI、python-docx、openpyxl 等依赖的许可原文随各依赖保留；精确版本见 package-lock.json 与 uv.lock。
- PyMuPDF 提供 AGPL / 商业许可路径。正式对外分发前，必须选择并落实相应许可义务或采购商业授权，不能将项目自身许可当作其替代。
- 本地 Tesseract 为用户自行安装的可选组件；当前安装包不捆绑 OCR 模型。模型服务商与用户文献的权利由对应来源约定。
- 发布签名证书、干净机器安装验收与真实文献质量验收尚需独立完成。

官方依据：[PyMuPDF 许可说明](https://pymupdf.readthedocs.io/en/latest/about.html)、[Electron 安全建议](https://www.electronjs.org/docs/latest/tutorial/security)。
